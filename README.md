
# 🔥 Fire Detection System using YOLO

## 📌 Overview

This project is an AI-powered fire detection system built using the YOLO model. It analyzes pre-recorded videos to detect the presence of fire. When fire is detected, the system automatically triggers an alarm and sends an instant Telegram notification to alert the user.

---

## ✨ Features

- 🔥 Fire detection from recorded videos
- 🎥 Video analysis using YOLO
- 🚨 Automatic alarm activation when fire is detected
- 📩 Instant Telegram notification
- ⚡️ Fast and accurate fire detection
- 🖥️ Simple and user-friendly interface

---

## 🛠️ Tech Stack

- Python
- YOLO
- OpenCV
- Flask
- PyTorch
- NumPy
- Telegram Bot API
